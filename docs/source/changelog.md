The [GitHub commit history](https://github.com/gomeshun/jeanspy/commits/main/)
records the full history. The
[release page](https://github.com/gomeshun/jeanspy/releases) identifies published
versions. A package version string in an unreleased checkout is not evidence
of a formal release. The documentation's `stable` alias will be created only
after the first non-prerelease GitHub release is published.
