# Draco: deferred public-data analysis

The designated input is the public spectroscopic catalogue in
[Walker et al. (2015), MNRAS 448, 2717](https://academic.oup.com/mnras/article/448/3/2717/1091040).
The reproducible recipe must freeze the exact input table and checksum,
repeat-observation handling, membership selection, coordinate origin and
rotation, distance and photometric constraints, likelihood and priors before
the final analysis is run.

This extended analysis is deferred under the author's release-first
[work plan](../validation/release-plan.md). This documentation branch provides
no completed Draco tutorial or J/D-factor constraint. The spherical and
axisymmetric synthetic workflow examples can be run independently.
