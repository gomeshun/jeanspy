Reproducible dynamical inference with JeansPy#

JeansPy solves spherical and axisymmetric Jeans equations for dwarf spheroidal galaxies. Build a tracer, halo and anisotropy model; predict velocity second moments; fit explicit priors and likelihoods with emcee or NumPyro; and retain the inputs and diagnostics needed to reproduce the analysis.

This is the development documentation. It may describe changes beyond the latest published package; use the source checkout in the installation guide.

Documentation version: dev. Source reference: 75be8c5ebb07. The release history identifies published versions; validation results apply to their stated models and domains.

Start with the installation guide and executable quickstart. The model contract defines units, geometry, array shapes and the limits of differentiation.
